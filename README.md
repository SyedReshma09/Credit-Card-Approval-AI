# Credit Card Approval AI

An intelligent web application that predicts credit card approval using machine learning. Built with Flask and Random Forest algorithm.

## 🌟 Features

- **AI-Powered Predictions**: Uses Random Forest algorithm for accurate credit card approval predictions
- **Interactive Dashboard**: Visual analytics of application data and trends
- **User-Friendly Interface**: Clean and responsive UI built with Bootstrap
- **Real-time Processing**: Instant prediction results with confidence scores
- **Comprehensive Data Analysis**: Visual insights into applicant demographics and financial patterns

## 📋 Prerequisites

- Python 3.8 or higher
- pip (Python package manager)
- Git (optional)
